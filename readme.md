# Hi 👋, we are Applied Motion Products

🌐 **Website:** [applied-motion.com](https://www.applied-motion.com/s/)

We design and manufacture motion control products — stepper and servo motors, drives, and controllers — for industrial automation. This GitHub presence collects example programs, application notes, and reference code to help engineers integrate our products into their systems.

## 📂 Our repositories

### PLC
- [CODESYS](https://github.com/AppliedMotionProducts/CODESYS) — sample programs and function block library
- [SIEMENS_PLC_Examples](https://github.com/AppliedMotionProducts/SIEMENS_PLC_Examples) — Siemens PLC Modbus TCP programs
- [Rockwell_PLC_Programs](https://github.com/AppliedMotionProducts/Rockwell_PLC_Programs) — Allen-Bradley examples for existing products (TXM, TSM, STF, ST, MDX, SV200, SSDC)
- [Rockwell_PLC_Programs_MDX_plus_M5](https://github.com/AppliedMotionProducts/Rockwell_PLC_Programs_MDX_plus_M5) — Allen-Bradley examples for the new MDX+ and M5 Servo EtherNet/IP products

### Python
- [EtherCAT_Python](https://github.com/AppliedMotionProducts/EtherCAT_Python) — motion control on EtherCAT products
- [Ethernet_Python_eSCL](https://github.com/AppliedMotionProducts/Ethernet_Python_eSCL) — Ethernet (eSCL) examples
- [Modbus_Python](https://github.com/AppliedMotionProducts/Modbus_Python) — Modbus TCP and RTU examples
- [Serial_Communication_using_Python](https://github.com/AppliedMotionProducts/Serial_Communication_using_Python) — RS-232/485 examples

### Other platforms
- [LabVIEW](https://github.com/AppliedMotionProducts/LabVIEW) — LabVIEW example programs
- [C-using-.NET](https://github.com/AppliedMotionProducts/C-using-.NET) — UDP communication via C# / .NET
- [Q_programs](https://github.com/AppliedMotionProducts/Q_programs) — example Q programs
